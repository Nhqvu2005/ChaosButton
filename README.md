# Button Chaos 🔴🔵

> **A fast-paced reflex game where every instruction depends on your previous move.**

**Button Chaos** is a brain-twisting reaction game that tests your memory and speed. Follow conditional instructions that evolve based on your last action—if you clicked Red before, you might need to click Blue now! Survive the timer, build your streak, and master the chaos.

![Chaos Button Gameplay Screenshot](https://via.placeholder.com/800x450.png?text=Button+Chaos+Gameplay)

## 🎮 How to Play
1. **Read the Protocol:** The instruction tells you which button to click.
2. **React Fast:** The timer is ticking down.
3. **Remember Your Steps:** Instructions become conditional (e.g., "If previous was Red...").
4. **Survive:** 3 mistakes = Game Over.

## ✨ Features
- **Conditional Logic:** Instructions adapt dynamically based on game state.
- **Escalating Difficulty:** Rules get harder every few rounds.
- **High Scores:** Tracks your best streak (saved locally for 365 days).
- **Neon Aesthetic:** Immersive dark mode UI with smooth animations.

## 🛠️ Built With

- CSS3 (Variables, Grid, Glassmorphism)
- Vanilla JavaScript (Zero Dependencies)
